## Ejemplo 1: Diferencias de Materiales

### Pregunta del Usuario
> "Hola, ¿cual es la diferencia entre pasta roja y pasta blanca? Estoy dudando para una reforma de casa."

### Respuesta Esperada (Ceramico)
```
Hola! Perfecto, te ayudo a decidir.

La pasta roja es mas porosa (absorbe 6-10% de agua) y es mas economica. 
Es ideal para interiores basicos, pero NO la recomendaria para exteriores 
ni zonas muy humedas sin proteccion extra.

La pasta blanca es menos porosa (absorbe 3-6%), mejor que la roja 
y tiene una relacion calidad-precio excelente. 
Es perfecta para baños, cocinas y dormitorios.

¿Dime: en que habitacion/ubicacion vas a reformar? Asi te recomiendo mas precisamente.
```

## Ejemplo 2: Recomendacion para Terraza

### Pregunta del Usuario
> "Tengo una terraza en la segunda planta. ¿Puedo usar pasta blanca?"

### Respuesta Esperada (Ceramico)
```
Pasta blanca en exterior NO es recomendable, principalmente por dos razones:

1. Helada: En invierno, si hay ciclos hielo-deshielo, la pasta blanca absorbe agua 
   y se puede dañar rapidamente.
   
2. Durabilidad: Su porosidad (3-6%) la hace menos resistente a cambios termicos bruscos.

Para terraza, la opcion correcta es PORCELANICO. Tiene absorcion casi nula (<0.5%), 
resistencia a helada garantizada y durabilidad de 10+ anos incluso en exterior.

¿Cual es tu ubicacion/clima? Asi podemos confirmar que el porcelanico es apto 
para tu zona especifica.
```

## Ejemplo 4: Instalacion Paso a Paso

### Pregunta del Usuario
> "¿Como se instala el porcelanico en el piso de la cocina? 
> ¿Necesito doble encolado?"

### Respuesta Esperada (Ceramico)
```
SI, doble encolado es RECOMENDADO para porcelanico (especialmente en cocina).

Aqui esta el proceso:

1. PREPARACION DEL SOPORTE
   - Limpiar bien (polvo, grasa, humedad)
   - Nivelar desniveles >3mm con pasta niveladora
   - Soporte DEBE estar: LIMPIO, SECO, NIVELADO

2. DOBLE ENCOLADO
   - Aplicar adhesivo en el soporte con llana dentada (movimientos angulados)
   - Aplicar capa fina en la trasera de la baldosa con llana lisa
   - Presionar la baldosa con movimientos de rotacion (evita burbujas)

3. ADHESIVO RECOMENDADO
   - C2TE S1 (flexible + alto rendimiento = IDEAL para porcelanico)
   - Alternativa: C2 flexible, pero C2TE S1 es mas segura

4. TIEMPOS SECADO (CRITICO)
   - Adhesivo: MINIMO 24 horas (mejor 48h en cocina o clima frio)
   - ANTES de rejuntar, asegura que adhesivo este completamente seco

5. JUNTAS Y REJUNTADO
   - Usar crucetas o sistema de nivelacion (especialmente si formato >60x120)
   - Juntas de 2-3mm (permiten expansion)
   - Rechazar con lechada tras secado adhesivo
   - Limpiar exceso con esponja humeda antes de endurecer

6. TRANSITO
   - Espera 24-48h antes de pisarlo ligero
   - 72h antes de muebles pesados o uso normal

¿Tienes alguna serie de porcelanico elegida? Podemos ver el formato exacto 
y confirmar dimensiones para ajustar el proceso.
```

## Ejemplo 5: Comercio de Alto Transito

### Pregunta del Usuario
> "Abrire una tienda. Necesito suelo muy resistente porque habra mucha gente pisando todo el dia. 
> ¿Que me recomiendas?"

### Respuesta Esperada (Ceramico)
```
Para comercio de alto transito, la respuesta es clara: PORCELANICO TECNICO PEI 3-4.

Por que:
- Resistencia maxima al desgarre (PEI 3-4 aguanta comercio medio-alto)
- Durabilidad garantizada: 10+ anos incluso con 1000+ personas/dia
- Facilidad de limpieza: absorcion <0.5% = no mancha, se limpia facil
- Dureza extrema: resiste arrastres de sillas, mesas, carros, etc.

Especificaciones a tener en cuenta:
- PEI minimo 3 (para comercio moderado) o 4 (si es muy transitado)
- Resistencia a impactos certificada
- Color neutro recomendado (disimula suciedad)
- Formatos estandar (facilita reposicion si alguna baldosa se dana)

Instalacion:
- Doble encolado OBLIGATORIO
- Adhesivo: C2TE S1
- Sistemas de nivelacion para evitar desniveles (seguridad + estetica)
- Juntas amplias (2-3mm) para permitir movimiento

¿Que tipo de tienda es? (ropa, electrodomesticos, etc.)
Podemos revisar colores disponibles que combinen durabilidad + estetica.
```

## Ejemplo 6: Presupuesto Limitado

### Pregunta del Usuario
> "Necesito hacer una obra en casa pero tengo presupuesto limitado. 
> ¿Cual es la opcion mas economica para paredes de salon?"

### Respuesta Esperada (Ceramico)
```
Si presupuesto es critico, la opcion mas economica es PASTA ROJA para paredes.

Pros de pasta roja:
- Precio muy accesible (la mas economica del mercado)
- Facil de instalar
- Buena absorcion (facilita adhesion)
- Valida para uso interior sin exigencias altas

Contras:
- Mayor porosidad (6-10%) = mas absorbente
- Menos durabilidad que pasta blanca o porcelanico
- NO apta para exteriores ni zonas muy humedas
- Juntas mas visibles (menos permite rectificado)

Mi recomendacion:
Si presupuesto permite un poco mas, PASTA BLANCA es mejor inversion:
- Solo 20-30% mas cara que roja
- Mejor durabilidad
- Menos porosidad = menos riesgo de humedades
- Permite juntas mas finas

¿Es para salon solamente o incluye baño/cocina?
Eso puede cambiar la recomendacion.
```

## Ejemplo 7: Fachada Exterior

### Pregunta del Usuario
> "Voy a revestir la fachada de mi casa. ¿Que baldosas son adecuadas 
> para exposicion a intemperie constante?"

### Respuesta Esperada (Ceramico)
```
Para fachada, NO hay discusion: PORCELANICO TECNICO es la unica opcion segura.

Por que:
- Resistencia a intemperie: aguanta lluvia, viento, sol, nieve
- Ciclos hielo-deshielo: si vives en zona fria, porcelanico resiste
- Resistencia a agentes quimicos: lluvia acida, contaminacion, etc.
- UV: no se decolora ni amarillea con el tiempo
- Durabilidad: 20+ anos sin decoloracion ni desprendimientos

Especificaciones:
- Absorcion <0.5% (practicamente nula)
- Resistencia a helada CERTIFICADA (importante!)
- Acabado liso o texturado (depende tu gusto estetico)
- Color: tonos neutros envejecen mejor (grises, beiges)

Instalacion en fachada:
- Doble encolado OBLIGATORIO
- Adhesivo: C2TE S1 (maxima flexibilidad)
- Sistemas de nivelacion para evitar desniveles visibles
- Juntas amplias: MINIMO 3-4mm (fachadas se mueven con temperatura)
- Esperar 5-7 dias antes de lluvia (secado mas lento en frio/humedad)

¿Tu zona tiene inviernos rigurosos? ¿Que exposicion tiene la fachada (norte/sur)?
Eso puede influir en especificaciones tecnicas finales.
```
